# Analysis of collected Workshop memories

Follow the [scheduled protocol](scheduled-protocol.md).
All evaluations use existing collected records and annex artifacts.
Synthetic corpora, simulated conversations, native trial generators and transport benchmarks were removed on October 7, 2026.
Their performance and compatibility findings are withdrawn.

Publicly accessible annex content is an appropriate source; preserve each record’s actual classification.
Record IDs, hashes and selection criteria make comparisons reviewable.
Missing evidence is a collection gap, not a reason to manufacture it.

The read-only `audit_data.py` can inspect retained records.
The pinned-source [PageIndex](pageindex-2026-10-02.md) and [ChatIndex](chatindex-2026-10-03.md) adapter reviews remain source assessments, not executed product evaluations.
