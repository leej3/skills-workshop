# Entire integration assessment

Reviewed October 7, 2026.
Decision: defer integration.

Role: optional capture and retrieval consumer, overlapping native conversation collection and the Workshop catalog.
The Workshop collector, portable envelopes and annex payloads remain independent.

The previous synthetic probes and derived compatibility claims have been withdrawn.
No maintained Entire adapter or demonstrated benefit on collected Workshop memories is established.
Reconstructing checkpoint Git trees would add an integration surface that has not earned its maintenance cost.

Source-reviewed boundary: [Entire’s checkpoint backend contract](https://github.com/entireio/cli/blob/main/docs/architecture/ref-checkpoint-backend.md) describes Git-shaped primary storage and non-Git mirrors.
[Entire Brain](https://github.com/entireio/entire-brain) is a possible downstream retrieval consumer.
These source observations are not a production compatibility result.
No hosted service or model dependency is required for Workshop storage.

Only reconsider for a concrete unmet capability.
The next discriminating test must use an existing annex capture, retain its original IDs and bytes, and compare utility and maintenance cost against direct Workshop retrieval.
Do not create synthetic conversations or checkpoint corpora.
