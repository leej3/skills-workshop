# Third-party source boundaries

The root MIT license and John Lee copyright apply to owned code.
They do not relicense upstream collections.
Collections are retained as Git submodule references, with exact commits recorded in the Git tree.
Their source histories and license files remain separate.

Before public redistribution or activation, review each selected upstream skill's license at the pinned commit.
A top-level collection license may have exceptions, skill-level licenses or separate document-tool terms.
Missing or unclear licenses remain unresolved; a Git pin is provenance, not permission to redistribute.
This repository does not flatten or relicense third-party source.

The pinned-license file inventory below is generated from Git objects, not from modified working-tree files.
