# Agent documentation

This directory is the default home for detailed documentation produced or maintained by agents: research ledgers, tool reviews, compatibility notes, evaluation protocols, and potential additions.

Keep these files current and decision-oriented:

- distinguish verified behavior from inference;
- link to primary sources and pin source-code evidence when relevant;
- state the research date for changing tools;
- remove superseded paths and dead-end proposals;
- prefer existing components over workshop-specific implementations; and
- identify what evidence would justify a proposed addition.

The parent [`docs/`](../) directory is reserved for concise, human-approved guidance.
Git history, rather than the active documentation tree, preserves old explorations.
