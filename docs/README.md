# Documentation

The concise, human-facing project guidance is the [skill-management executive summary](skill-management-executive-summary.md).

Detailed research, working assessments, and agent-maintained references live in [`docs/agents/`](agents/).
Material should be promoted from that directory only after a human approves it and it has been condensed into durable decisions or guidance.

Historical experiments and superseded proposals should be removed rather than kept in the active documentation tree.
Git history remains the archive.
